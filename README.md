# Personal Portfolio Website

This is my first web development project, created using HTML and CSS.

The website consists of two pages:

- Home Page
  - Personal introduction
  - About Me section
  - Interests section
  - Projects section

- Contact Page
  - Contact information
  - Easy way for visitors to reach me

## Technologies Used
- HTML5
- CSS3

## Project Goal
The purpose of this project is to practice web development fundamentals and build a professional portfolio website. Through this project, I learned how to create multi-page websites, structure content using HTML, and style web pages using CSS.
